# Beauty Inspector

Telegram-first сервис с агентным конвейером, который находит салон красоты,
проверяет обязательные данные и формирует короткий текстовый отчёт.

## Что уже работает

- Telegram-бот: обычное сообщение или команда `/report`;
- HTTP API `POST /reports`;
- 2ГИС Places API: название, адрес, рейтинг, число оценок и часы работы;
- Google Places как дополнительный источник при наличии ключа;
- demo-провайдер для локальной разработки без внешних ключей;
- выбор критериев отчёта: рейтинг, отзывы, цены, услуги, мастера, слоты;
- ИИ-выжимка из собранных отзывов: общая картина, повторяющиеся плюсы,
  минусы и важные оговорки;
- отсутствующие данные честно отмечаются как `нет данных`.

Google Places не является источником конкретного прайса, списка мастеров и
свободных окон. Эти данные должны поступать из сайта салона или платформы
онлайн-записи через отдельные коннекторы.

## Архитектура и агенты

```text
Telegram / HTTP API
        ↓
Агент 1 — Collector → источники → SalonProfile
        ↓
Агент 2 — Reviewer → рейтинг + отзывы + конкретные цены
        ↓
Агент 3 — Publisher → проверенный отчёт → Telegram
        │
        └── данных мало → Reviewer → Collector (повторный сбор)
```

Провайдерный интерфейс объединяет доступные источники и позволяет добавлять
Яндекс, Zoon и системы записи, не меняя Telegram-бота и формат отчёта.

Publisher никогда не публикует непроверенный отчёт. После двух безуспешных
попыток бот сообщает, каких обязательных полей не хватает.

## Запуск

Требуется Python 3.12+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
pip install -e ".[dev]"
copy .env.example .env
```

Для первого запуска оставьте `DATA_PROVIDER=demo`, добавьте токен от
`@BotFather` и запустите:

```bash
python -m app.bot
```

Примеры:

```text
gsnv lab
GSNV-LAB Астрахань
gsnv lab в городе Казань
/report Париж | Астрахань | рейтинг, отзывы, цены
```

Для обычного запроса разделители не нужны: бот не учитывает регистр букв,
схлопывает лишние пробелы и использует город по умолчанию. Город можно написать
естественной фразой `в городе Казань`. Формат с `|` нужен только для явного выбора
города и критериев отчёта.

HTTP API:

```bash
uvicorn app.api:app --reload
```

```http
POST /reports
Content-Type: application/json

{
  "query": "Париж",
  "city": "Астрахань",
  "criteria": ["rating", "reviews", "prices"]
}
```

Для Google Places включите Places API (New), создайте API-ключ и задайте:

```env
DATA_PROVIDER=google
GOOGLE_PLACES_API_KEY=...
```

Для рабочего российского сценария:

```env
DATA_PROVIDER=multi
TWOGIS_API_KEY=...
DEFAULT_CITY=Астрахань
```

Для аналитической выжимки по отзывам добавьте:

```env
REVIEW_SUMMARY_PROVIDER=local
REVIEW_SUMMARY_MAX_CHARS=700
```

`local` — бесплатный режим без внешнего API. Для перехода на OpenAI:

```env
OPENAI_API_KEY=...
OPENAI_REVIEWS_ENABLED=true
OPENAI_REVIEW_MODEL=gpt-5.6-luna
REVIEW_SUMMARY_PROVIDER=openai
REVIEW_SUMMARY_MAX_CHARS=700
```

Без `OPENAI_API_KEY` сервис продолжит работать и покажет несколько исходных
отзывов вместо ИИ-выжимки.
